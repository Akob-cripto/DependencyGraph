# DepGraph

CLI-инструмент для визуализации графа зависимостей пакетов менеджера пакетов **Alpine Linux (apk)**.
Проект разработан в рамках учебного задания и позволяет парсить конфигурацию, получать данные о зависимостях из репозитория и строить граф с возможностью визуализации.

## Стек технологий
*   **Язык:** Kotlin (JVM)
*   **Сборка:** Gradle
*   **Парсинг XML:** Стандартная библиотека Java (`javax.xml.parsers`)
*   **Работа с сетью:** Стандартная библиотека Java (`java.net.http`)
*   **Визуализация:** PlantUML (через вызов внешнего `plantuml.jar`)

## Требования к окружению
*   JDK 17 или выше (проект тестировался на OpenJDK 25).
*   Установленный Gradle (или использование wrapper-скрипта `./gradlew`).
*   Для генерации SVG-картинок: файл `plantuml.jar` в корне проекта (опционально, программа работает и без него, сохраняя только `.puml`).
